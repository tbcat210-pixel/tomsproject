最短セットアップ（GitHub + Netlify）

1. このZIPを展開し、中身をGitHubのリポジトリへアップロードします。
2. Netlify → Add new project → Import an existing project → GitHub でそのリポジトリを選びます。
3. Publish directory は docs です（netlify.tomlで設定済み）。
4. GitHub → Actions → Collect X trade data → Run workflow を1回押します。
5. 初回実行で「現在より前の直近7日」も遡って取得します。
6. 以後は毎時17分・47分に新着取得。約24時間ごとに7日分を自動で再走査します。

過去7日を今すぐ取り直す:
GitHub → Actions → Force 7-day historical backfill → Run workflow

重要:
NetlifyへZIPを直接ドラッグしただけでは、GitHub Actionsが動かないのでデータは自動更新されません。
過去データ取得と自動更新にはGitHub連携を使ってください。

画像メーカー対応:
- GameWith等の「欲しいカード/出せるカード」「求/譲」画像をOCR解析します。
- package.json に tesseract.js を追加済みです。Actionsでは npm install が走ります。
- 初回OCRは言語データを取得するため通常より時間がかかる場合があります。
- OCR結果は docs/data/ocr-cache.json に保存されます。
