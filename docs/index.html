集計方法

Yahoo!リアルタイム検索で取得できる公開Xポストをページ送りし、初回から直近7日を遡及収集します。本文に加えて、GameWithなどのトレード画像メーカー画像も日本語OCRで解析します。小さいカード画像が複数並ぶメーカー画像に対応するため、拡大・二値化・分割OCRを行います。「欲しいカード / 求」を需要、「出せるカード / 譲」を供給として★2サポート名を照合し、Yahoo!リアルタイム検索で取得した検索ヒットを基準に集計します。通常は30分ごとに新着を取り込み、約24時間ごとに7日分を再走査して取りこぼしを補完します。
